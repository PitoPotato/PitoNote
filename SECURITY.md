# Security

Do not post private notes, exports or full data files in public issues.

Use **Security → Report a vulnerability** if the maintainer has enabled private reporting. Otherwise ask for a private contact without disclosing exploit details or personal data. No separate contact is configured in this source snapshot.

Trust boundaries include literal note text, JSON imports, note IDs/paths, Rainmeter commands and draft persistence. Install trusted builds only. The helper is unsigned; this project has not undergone an independent security audit.
